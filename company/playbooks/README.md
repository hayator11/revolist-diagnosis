# 📚 プレイブック — 「どうすればいいか」を読みに行く場所

作業の型（やり方）を貯める場所。新しい仕事のとき、部長と各担当はまずここを見る。
ここに手順があれば再現でき、なければ一度やって手順をここに書き足す（＝会社が育つ）。

## 一覧
| プレイブック | 用途 |
|---|---|
| [`00-standard-operating-procedure.md`](./00-standard-operating-procedure.md) | **全案件共通の進め方（SOP）**。どんな依頼もこの型で回す |
| [`threads-campaign.md`](./threads-campaign.md) | Threads発信案件の進め方（@____hayator／レボリスト診断） |

## 書き方のルール
- 1プレイブック＝1つの「やり方」。手順は番号つきで、迷わない粒度に。
- 使ったツール・出力先・チェック項目を必ず書く。
- うまくいった型・外した原因は、該当プレイブックか担当の成長ログに追記する。
