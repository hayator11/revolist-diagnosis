## 2. 誰に呼びかけるか（集めたい仲間像）

**ネガに言わない。「こういう力を持つ人へ」と、力の名前で呼びかける。**
11タイプそのものが呼びかけの言葉になる。誰か一人を選ぶのではなく、**11通りの入口をそれぞれ開く**。

| 呼びかけの言葉（例） | 響く力（対応の方向性） |
|---|---|
| 「最初に動き出す火種を持っている人へ」 | レボリスト |
| 「頭の中の理想を、形にしたくてうずうずする人へ」 | マックスデザイナー／イメージマイスター |
| 「人と人をつなぐのが自然にできる人へ」 | コミュニケーター |
| 「気になったら深く調べずにいられない人へ」 | インフォレイダー |
| 「場の空気を前に動かす力がある人へ」 | ムーブメンター |
| 「細部まで丁寧に仕上げたくなる人へ」 | プルミエルクラフター |
| 「筋道を立てて考えるのが得意な人へ」 | ロジカルマイスター |
| 「バラバラなものを噛み合わせる人へ」 | アレンジャー |
| 「自分の芯を大事にしたい人へ」 | ソウルオーナー |
| 「まだ誰もやっていないことを試したい人へ」 | クレイジスト |

**さらに広い一言（全タイプ横断の呼びかけ）**
- 「自分の“力”をどう活かせばいいか、言葉を探している人へ。」
- 「一人でやってきたけど、誰かと組んでみたくなった人へ。」
- 「発信してみたい、でも何から言えばいいか迷っている人へ。」

> ⚠️ NG例（使わない）：「行動できない人」「うまくいかない人」「向いてない人」。
> → すべて **「◯◯の力を持つ人へ」** の肯定形に置き換える。

## 3. 仲間集め版・発信の柱（既存3本柱の再定義）

`00-strategy.md §3.1` の3本柱（配分 A:B:C = 4:3:3）はそのまま維持し、**各柱の“ゴール”を仲間集めに読み替える**。

| 柱 | 既存の目的 | 仲間集め版の目的 | 合言葉 | 推奨形式（既存踏襲） |
|----|-----------|-----------------|--------|-----------------|
| **A. 11タイプ紹介** | 認知・自分ごと化 | **入口＝名乗らせる**。「これ私だ」と手を挙げてもらう | 「名乗ろう」 | 画像カルーセル＋短文＋問い |
| **B. よくある特性** | 共感・保存 | **共感＝つながる**。「わかる」で会話が生まれ、顔見知りになる | 「つながろう」 | テキスト主体 |
| **C. 組み合わせ** | 参加・巻き込み | **一緒にやる**。違う力どうしが組む面白さ→“一緒に発信”へ | 「組もう」 | ハイブリッド |

### A：入口（名乗らせる）
- 到達点：読んだ人が **「私は◯◯タイプかも」とコメント/引用で名乗る**。
- 投げ方：タイプの「力」を主役に描く。締めは「あなたはどれに近い？」。
- 受け止め方：名乗ってくれたら**そのタイプの一言（強みや動き方）を返す**。名乗りは仲間名簿の一行目。
- 注意：この段では診断リンクを前に出さない（`00-strategy §3.5`）。まず“名乗り”を最優先。

### B：共感（つながる）
- 到達点：「わかる」返信が積み上がり、**同じ特性どうしがゆるく顔見知りになる**。
- 投げ方：あるある・比較・小さなエピソード。テキストで軽く毎日。
- 受け止め方：「わかる」には共感で返し、**似た人どうしを緩く紹介**（「この感覚、◯◯さんも言ってた」）。点を線にする。
- 注意：ここは会話の“居心地”をつくる段。強いCTAは出さない。

### C：一緒にやる（組もう）
- 到達点：違う力どうしの組み合わせに興味が向き、**「一緒にやってみたい」が芽生える**。
- 投げ方：2タイプの相性・3人目・チーム設計（差別化の核＝`00-strategy §1 追い風`）。締めは「あなたの相方は？」「このチームに足りない力は？」。
- 受け止め方：組み合わせの提案に乗ってくれた人へ、**“一緒に発信してみない？”の小さな誘い**をかける（第4段へ）。
- 注意：Revoは出口。押しつけず、「試せる場所がある」と**触れる程度**に。

## 4. 仲間になるまでの導線（5段）

各段で **①何を投げるか ②どう受け止めるか ③次にどう誘うか** を定義。
段が進むほど関係が深まる。**急がない・押しつけない**が鉄則（会話最優先＝アルゴリズムとも一致）。

### 第1段：名乗り（Recognize）
- **投げる**：柱Aの「力の名前」。「これ、あなたのことかも」と鏡を差し出す。
- **受け止める**：名乗り（コメント/引用/いいね）を**必ず拾って一言返す**。名乗ってくれた人を軽くメモ（仲間の入口一覧）。
- **次へ誘う**：「その力、こんな場面で出てない？」と**具体を1つ聞く**→会話（第2段）へ橋渡し。

### 第2段：会話（Talk）
- **投げる**：柱Bのあるある・問い。相手が一言で答えられる軽さで。
- **受け止める**：全返信に返す（`00-strategy §3.4`）。**相手の言葉を引用して返す**と関係が深まる。
- **次へ誘う**：「似た感覚の人、もう一人いてね」と**横のつながりを示唆**→ゆるい共同体感（第3段）へ。

### 第3段：参加（Join）
- **投げる**：軽い参加企画。「あなたのタイプで一言」「#私の力 で名乗ってみて」等の**参加型の問い**。
- **受け止める**：参加してくれた投稿を**引用・紹介**して可視化。「参加した人がいる」空気をつくる。
- **次へ誘う**：「今度これ一緒にやってみない？」と**共同アクションの打診**（第4段）へ。

### 第4段：仲間化（Team up）
- **投げる**：柱Cの組み合わせ発。「違う力どうしで組むと何が起きるか」を見せ、**“一緒に発信する”を具体提案**。
- **受け止める**：乗ってくれた人と**役割を言葉にする**（「あなたは火種、私は整える側」）。組み合わせをそのまま関係にする。
- **次へ誘う**：「もっと自分の力を試したくなったら、こんな場所があるよ」と**Revoを出口として初めて自然に置く**（第5段）。

### 第5段：診断／Revo遷移（Grow）
- **投げる**：ここで初めて**診断への強めの導線**（`00-strategy` はWeek4）＋Revoの紹介。
- **受け止める**：診断結果を見せてくれた人に**タイプに沿った一言**。結果は会話の新しい入口。
- **次へ誘う**：「その力を活かせる場所」としてRevoへ。**押しつけず、選択肢として**。ここが“出口”。

> 5段の要約：**名乗り → 会話 → 参加 → 仲間化 → 診断/Revo**。
> 各段の合言葉：**気づかせる → 返す → 巻き込む → 組む → 送り出す**。

## 5. CTAの型（答えたくなる／参加したくなる呼びかけ雛形）

各段で使う。**一問一答で答えられる軽さ**を保つ。診断リンクは第5段まで前に出さない。

### 第1段：名乗りCTA（Aの締め）
- 「あなたは、どの“力”に一番近い？」
- 「この中に、"これ私だ"ってタイプ、いた？」
- 「一言でいうと、あなたはどんな力を持ってる人？」
- 「名前をつけるなら、あなたの力はどれ？」

### 第2段：会話CTA（Bの締め）
- 「これ、"わかる"ってなった人？」
- 「あなたの場合はどう？一言で教えて。」
- 「似た感覚の人、いる…？（手を挙げて）」
- 「あなたはこういう時、どう動く？」

### 第3段：参加CTA（企画の締め）
- 「あなたのタイプで、一言だけ名乗ってみて。」
- 「#私の力 をつけて、あなたの強みを書いてみて。」
- 「あなたと"違う力"を持つ友達、思い浮かぶ？タグ付けしてみて。」
- 「この問い、あなたならどう答える？（引用で回して）」

### 第4段：仲間化CTA（Cの締め）
- 「あなたの"相方"になりそうな力は、どのタイプ？」
- 「このチームに足りない力、どれだと思う？」
- 「一緒に発信してみたい人、ゆるく手を挙げてみて。」
- 「あなたの力と私の力、組んだら何ができそう？」

### 第5段：遷移CTA（診断／Revo）
- 「自分の力、ちゃんと言葉にしてみたくなったら → 診断でどうぞ（プロフィールから）。」※リンクは**仮置き**、公開前に差し替え
- 「その力を試せる場所、探してるなら。こんな場があるよ。」（Revoを出口として自然に）
- 「結果、よかったら見せて。あなたの力に一言そえるね。」

> ⚠️ すべての段で **ネガ表現ゼロ**。「足りない力」は“これから足す伸びしろ”の意味で使い、人を下げる意味では使わない。

## 7. 計測（仲間集め5段ファネル）

> この章の担当：📊 アナリティクス部。`13-analytics-kpi.md`（既存KPI）を**土台**にし、その上に「知らない人を“仲間”に変える」計測レイヤーを重ねる。
> North Star＝**返信率（返信数÷リーチ）** は据え置き。仲間集めは補助指標で見る。
> トーンの鉄則：ネガティブ表現ゼロ。**外れた投稿は「欠点」ではなく「次の仮説のタネ」**。名乗ってくれない投稿＝まだ入口が固いだけ、次の入口を試すサイン。
> **すべての数値は「初期の仮置き」**。合否ラインではなく“観測の出発点”。最初の2〜3週の実データが出たら自分の中央値に置き換える。

**この章の3行まとめ**
1. 既存ファネル（返信→プロフ遷移→診断）は**アルゴリズムを動かすエンジン**。その上に**「知らない人を“仲間”に変える」5段ファネル**を重ねる。
2. 5段＝**名乗り → 会話 → 参加 → 仲間化 → 診断/Revo遷移**（＝§4の第1段〜第5段と完全に同じ導線・同じ呼び名。計測側では S1〜S5 と略記する）。各段は「1投稿1分の手動カウント」で測る。
3. North Starは**返信率のまま**。仲間集めは補助指標（新規名乗り数／再訪コメント者数／フォロー転換）で見る。

### 7.1 仲間集め5段ファネル

既存KPIツリー（`13-analytics-kpi.md §1`）が「リーチ→返信→保存→プロフ遷移→クリック→診断実行」の**タテの流れ**なら、こちらは同じ会話の中で**「人が“仲間”に育っていくヨコの流れ」**を測る。両者は別物ではなく、返信（既存の最重要KPI）が2段目にそのまま入る＝土台を共有する。

```
[S1] 名乗り     … コメントで自分のタイプ／特性を口にした人  ← §4 第1段（名乗り／Recognize）
        ▼   （“わかる”の一歩先。自己開示が起きた）
[S2] 会話       … 返信ラリーが往復した（=既存の★返信KPIと接続）  ← §4 第2段（会話／Talk）
        ▼   （一往復で終わらず、こちらの返信に再返信が来た）
[S3] 参加       … クイズ回答・タグ付け・お題乗っかりなど“遊びに乗った”  ← §4 第3段（参加／Join）
        ▼   （受け身の会話から、能動アクションへ）
[S4] 仲間化     … フォロー or 2回目以降のコメント（常連化）  ← §4 第4段（仲間化／Team up）
        ▼   （単発の接触から、継続関係へ）
[S5] 診断/Revo遷移 … 診断リンク着地／Revo文脈に反応（“出口”へ自然到達）  ← §4 第5段（診断/Revo遷移／Grow）
```

> **呼び名の対応（両章で統一）**：S1〜S5 は §4 の第1段〜第5段と1対1で対応する。呼び名は **名乗り → 会話 → 参加 → 仲間化 → 診断/Revo遷移** で完全一致。§4は「どう誘うか（会話設計）」、本章は「どう数えるか（計測）」を担当する。

#### 各段の指標・測り方・初期の仮置き

| 段 | 指標名（ログ列） | 何を表すか | 測り方（手動1分） | 初期の仮置き目安 |
|----|----------------|-----------|------------------|----------------|
| **S1 名乗り** | `namers`（新規名乗り数） | コメントで「私は〇〇タイプ」「これわかる、私も」等、**自分の特性を口にした人数** | 投稿のコメント欄をざっと見て、自己開示コメントを**指折り数える**。ハンドル名を後述の名簿にメモ | **1投稿あたり2人以上**（まず“最初の1人”が名乗るかを見る） |
| **S2 会話** | `rally`（返信ラリー往復数） | 一往復で終わらず**こちらの返信に再返信が来た会話の数** | こちらが返した相手のうち、**さらに返ってきた本数**を数える（既存 `replies_total` の“濃さ”版） | **1投稿あたり1ラリー（2往復）以上** |
| **S3 参加** | `join`（参加アクション数） | クイズ回答・**タグ付け**・お題乗っかり等、能動アクションをした人数 | 「〇〇な友達をタグ付け」「あなたの相方は？」等の**指名・選択・タグ**に反応した数を数える | **参加を促す投稿で3件以上**（C柱＝巻き込み系を主戦場に） |
| **S4 仲間化** | `regulars`（再訪コメント者数） | **2回目以降**コメントした人＋**その投稿きっかけの新規フォロー**の人数 | コメント名を名簿（§7.3）と照合し**既出=再訪**をカウント。フォロー増は週次でまとめて | **週あたり再訪コメント者3人以上／新規フォロー手応え** |
| **S5 診断/Revo遷移** | `to_diag`（遷移の手応え） | 診断リンク着地・Revo文脈への反応（“出口”到達） | 既存 `link_clicks` と `?src=threads` 計測を流用。コメントで「診断やってみた」等の**言及も1件と記録** | **週あたりクリック＋言及で合算し傾向を観測**（初期は有無だけでOK） |

> ポイント：S1〜S3は**コメント欄を見れば1分で数えられる**。S4・S5だけは名簿照合とリンク計測が要るので**週次でまとめて**でよい。日々の負荷はS1〜S3の3つの数字だけ。

#### 段が落ちても「欠点」にしない読み方（トンマナ）

- S1で名乗りが薄い → 問いが“自己開示しにくい形”だっただけ。**次は「あなたはどっち？」の選択型**を試すタネ。
- S3で参加が伸びない → まだ“遊びの余白”が足りないだけ。**タグ付け・指名の一言を足す**タネ。
- どの段も「落ちた＝失敗」ではなく**「次にどの入口を開けるか」の手がかり**として記録する。

### 7.2 North Star と補助指標

#### North Star は据え置き

- **週次North Star＝返信率（返信数 ÷ リーチ）**。既存 `13-analytics-kpi.md §1.3` のまま**変更しない**。
  - 理由：返信はアルゴリズム上の生命線であり、仲間集めの土台（S2）でもある。**軸をブラさない**。
- **月次の事業North Star＝診断実行数**も据え置き。仲間集めは、この2つを損なわずに**厚みを足す**役割。

#### 仲間集め視点の補助指標（3つ・すべて仮置き）

North Starを主役に置いたまま、**「会話が“仲間”に育っているか」**を見る補助3指標を足す。

| 補助指標 | 定義 | なぜ見るか | 初期の仮置き目安 | 見る頻度 |
|---------|------|-----------|----------------|---------|
| **① 新規名乗り数** `namers` | その週に**初めて**自己開示コメントをした人数（名簿の新規行） | ファネルの入口の広さ。仲間の“新規流入” | **週10人以上**（まずは増加傾向だけ見る） | 週次 |
| **② 再訪コメント者数** `regulars` | その週に**2回目以降**コメントした人数（名簿で既出） | 関係の継続。仲間化の中核指標 | **週3人以上**（1人でも“常連の芽”） | 週次 |
| **③ フォロー転換** `follow_conv` | 新規フォロー数 ÷ その週の新規名乗り数 | 名乗った人がどれだけ定着したか | **20%前後を観測開始ライン**（例：名乗り10→フォロー2） | 週次 |

> 注記：③フォロー転換の“正確な紐付け”は難しい。**厳密な因果ではなく「名乗りが増えた週にフォローも増えたか」の傾向**として見れば十分。数値は全部**初期の仮置き**で、2〜3週の中央値が出たら更新する。

#### 指標の優先順位（迷ったらこの順で見る）

```
返信率（★North Star・据え置き）
  └→ ① 新規名乗り数（入口が開いたか）
       └→ ② 再訪コメント者数（仲間になったか）
            └→ ③ フォロー転換（定着したか）
                 └→ 診断/Revo遷移（出口へ届いたか）
```

### 7.3 記録様式（投稿ログに足す列）

#### 投稿ログへの追加列（既存 `13-analytics-kpi.md §2.1` の表に足す）

既存の必須列は変えず、**仲間集め観点の列を数個だけ追加**する。日々埋めるのはS1〜S3の3列で十分。

| 追加列名 | 型 | 入力例 | いつ埋める | メモ |
|---------|----|-------|-----------|------|
| **namers** | 数値 | `3` | 投稿数時間後 | S1：自己開示コメントした人数（新規名乗り） |
| **rally** | 数値 | `2` | 投稿数時間後 | S2：再返信まで来た会話（往復）の数 |
| **join** | 数値 | `4` | 投稿数時間後 | S3：タグ付け・指名・クイズ等の参加アクション数 |
| regulars_hit | 数値 | `1` | 週次でまとめて可 | S4：この投稿で再訪（既出名簿）した人数 |
| new_names | 文字 | `@aaa,@bbb` | 投稿数時間後（任意） | S1で**初めて**名乗った人のハンドル。名簿へ転記する元 |

> **最小構成（時間がない日）**：追加は **`namers` / `join` の2列だけ**でも回る。まずここから。既存の `replies_total`（返信数）がS2の代理になるので、`rally` は余裕があれば。

#### 別シート「仲間名簿」（超軽量・任意だが推奨）

S4（仲間化）を測るには「同じ人が2回来たか」を照合する必要がある。**専用ツールは不要**。1行1人の軽い名簿で足りる。

| 列名 | 型 | 入力例 | メモ |
|------|----|-------|------|
| handle | 文字 | `@revo_taro` | Threadsハンドル |
| first_post | 文字 | `B-04` | 初めて名乗った投稿のpost_id |
| first_date | 日付 | `2026-07-15` | 初コメント日 |
| touches | 数値 | `3` | 累計コメント回数（来るたび+1） |
| followed | 選択 | `Yes` | フォローされたら Yes |
| type_said | 文字 | `ソウルオーナー` | 名乗ったタイプ（分かれば） |
| note | 文字 | `診断やってみたと報告` | ひとことメモ |

> 使い方：新しいコメント者は1行追加、既出なら `touches` を+1。**再訪＝touches≥2**。これだけでS4と補助指標①②が両方出る。名簿が重い日は `new_names` 列にハンドルを溜めておき、週次でまとめて転記でよい。

### 7.4 週次レビューに足す観点

既存の週次レビュー（`13-analytics-kpi.md §3`）の**サマリーと問いに、仲間集めブロックを1つ追加**する。所要は+3〜5分。§6の週次レビューと同じ週の作業として一緒に回す。

#### サマリーに足す行（コピペ用）

```
## 仲間集めサマリー（今週）
- 新規名乗り数（①）：__人　／　再訪コメント者数（②）：__人
- フォロー転換（③）：__%（新規フォロー__ ÷ 名乗り__）
- 5段ファネルの通過感：名乗り__ → 会話__ → 参加__ → 仲間化__ → 遷移__
```

#### 追加する問い（★今週の主役）

```
## 今週“仲間”になったのは誰か（★仲間集めの本体）
- 新しく常連になった人：@____（きっかけ投稿：post_id ____ ／ 名乗ったタイプ：____）
  - なぜこの投稿がきっかけ？：____（例：選択型の問いで名乗りやすかった）
- 再訪してくれた人：@____（前回：____ → 今回：____）
- “仲間化”を生んだ投稿の型：____（翌週コピーする1つ）

## 来週の仲間集め仮説（1つでOK）
- 仮説：____（例：タグ付け型は参加S3が伸び、名簿の新規行が増える）
```

> 狙い：週次を「数字の反省会」にしない。**「今週どの投稿が、どの人を仲間にしたか」を1つ言語化して、その型を翌週コピーする**。既存レビューの「伸びた投稿TOP3」と同じ思想を、人（仲間）軸に広げるだけ。

#### 運用リズムへの追記（既存 `13-analytics-kpi.md §6` に足す）

| タイミング | 足すこと | 所要 |
|-----------|---------|------|
| 投稿数時間後 | ログに `namers / join`（＋余裕あれば `rally`）を追記／新規コメント者を名簿へ | +1分 |
| 毎週 | 仲間集めサマリー＋「今週仲間になったのは誰か」を記入 | +3〜5分 |
| 隔週〜月次 | 補助指標①②③の仮置きを自分の中央値へ更新 | 既存に内包 |
