## 4. 次のバッチを作る手順（＝エンジン本体・1回でN投稿増える）

**1バッチ＝1週間分（7投稿）**を標準とする。この5ステップを回すたびに**予約表が7投稿ぶん伸びる**。所要は慣れると**1バッチ90〜120分**（画像込み）。

```
[バックログ] → ① ライター → ② デザイン → ③ 編集長 → ④ 予約表追記 → ⑤ 保存
   §3から7枠   コピー化      画像書き出し   トンマナ監査   Buffer形式化   exports/へ
```

### ① ライター（コピー化）｜目安40分
- §3バックログから**今週の7枠**を取り、§2週次型の曜日に割り付ける。
- 各投稿を**黄金構造**で書く（`00-strategy §3.2`）：①フック1行 ②本文〜500字 ③締めの問い（必須）④タグ1個。
- ネタ元フィールドを**そのまま素材化**：柱C＝`combinations.ts` の `title`/`quote` を核に。柱B＝`actionPrinciples`/`currentEnvTips`/`howToCheer` を箇条書き化。フック・締めは `11-copy-stock.md` の**雛形10個**をローテ使用（同型連投を避ける）。

### ② デザイン（画像）｜目安30分
- 柱A＝`exports/01〜11-*.png` を**再利用**（再カットは表紙コピーだけ差し替え）。
- 柱C＝`card-templates.html` をブラウザで開き、**2色（相性）／3色（3人チーム）カード**を1080×1350で書き出し、`exports/` に `cN-*.png` として保存。まとめは20枚カルーセル。
- 画像不要（柱B・参加のテキスト主体）はスキップ。

### ③ 編集長（監査）｜目安15分
- **禁止語チェック**：相性が悪い／向いていない／弱点／欠点／失敗／劣る＝**0件**。
- **原則チェック**：優劣なし・全員主役／タグ**各1個**／`#自分を推し活` は柱A本文のみ／**Revoは本文に出さない**（出口はプロフィール）／「世界一」は断定しない姿勢語のみ。
- **カデンス**：同日2投稿は4時間以上／主軸曜日に柱C／時間帯（昼画像・夜テキスト）。
- **重複**：§5の重複回避ルールに照合（同一ペア同週なし／フック・締めの型が連続しない）。

### ④ 予約表追記（スケジュール）｜目安10分
- `BUFFER-SCHEDULE.md` の形式（**1投稿＝1ブロック：予約日時JST／添付画像／タグ／［そのまま貼る全文］**）で7ブロック追記。
- pin・クイズの夜正解・初速60分返信は**Buffer外の手動運用**と明記（既存注記を踏襲）。

### ⑤ 保存
- 書き出した画像は `exports/` へ、追記した予約ブロックは `BUFFER-SCHEDULE.md`（または週別に `BUFFER-W3.md` 等）へ保存。git は触らず**つばさが一括**。
- **バックログ§3の消化行に取り消し線**を引き、次バッチの起点を1行メモ（例「次はW7＝crazist×communicatorから」）。

## 5. 枯れない工夫（重複回避・良い型のコピー・季節枠）

### 5.1 同じ切り口の重複を避けるルール
- **同一ペアは同一週に出さない**。柱Cは `combinations.ts`(110)＋`goodWith`(33)＋`teamDesign`(11)で**切り口が3層**あるので、同じ2タイプでも「相性」「3人チーム」「あるある共感」に**役割を分けて**別週に配置。
- **フック雛形・締めの問い雛形（各10個＠`11-copy-stock.md`）をローテ**。同型を2連続で使わない（例：数字回答型の翌日は選択型）。
- **使用済みを予約表で照合**：`BUFFER-SCHEDULE.md` が使用済みログを兼ねる。バッチ着手前に「直近14投稿の柱・ペア・フック型」を見て被りを外す。

### 5.2 反応が良い型を翌週コピー（アナリティクス連携）
- `13-analytics-kpi.md §3` の週次レビュー「伸びた投稿TOP3」と、`20-broadcast-axis §7` の **`namers`（名乗り）・`join`（参加）が伸びた投稿**を確認。
- 伸びた投稿の**フック＋締めの問い＋形式**を、次バッチの雛形として**1枠コピー**（ネタ元だけ差し替える）。「型は複製、素材は更新」でネタは減らさず精度を上げる。
- 外れた投稿は**欠点にしない**（`20-broadcast-axis §7` トンマナ）。「入口が固かった＝次に試す入口のタネ」として1行記録。

### 5.3 季節・イベント差し込み枠
- 週次型の**土枠（または予備枠）に季節・行事を1つ**差し込める余地を常に空ける：新年度/進級・大型連休・試験期・忘年会/新年のチーム編成・帽祭など地域イベント。
- 季節ネタも**11タイプ×行事**で量産可（例：「新年度、最初に手を挙げるのはレボリスト」）。ネタ元は既存フィールドのまま、文脈だけ季節に寄せる。
- **イベント告知はリンク例外**（`EVENT-x-benkyokai.md §0`）。通常投稿は診断リンクを本文に貼らない原則を維持。
