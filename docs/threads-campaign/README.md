# レボリスト診断 × Threads 発信キャンペーン

Threads `@____hayator` で、レボリスト診断の11タイプを画像ベースで発信するための設計一式。

## 何が入っているか

| ファイル | 内容 |
|---------|------|
| [`00-strategy.md`](./00-strategy.md) | **発信の仕組み設計**（2026年Threadsアルゴリズム調査＋投稿システム＋4週間ロードマップ＋KPI） |

## 3分でわかる要点

1. **Threadsは2026年、「いいね」より「返信（会話）」を最重視**。→ 毎投稿の末尾に“答えたくなる問い”を必ず入れる。
2. **初速（投稿後60分）が勝負**。→ 投稿したら返信担当になり、全コメントに返す。
3. **画像かテキストか＝ハイブリッドが正解**。画像で止めて、テキストの問いで会話させる。タイプ紹介は画像必須、あるある系はテキスト主体、組み合わせはハイブリッド（詳細は `00-strategy.md` §1.5）。
4. **3本柱**：A. 11タイプ紹介／B. よくある特性／C. 組み合わせで能力アップ。
5. **診断への強いCTAはWeek4のまとめ投稿まで我慢**。それまでは会話（返信）を最優先。

## トーンの鉄則（診断の大原則をSNSでも）
ネガティブ表現は使わない（相性が悪い／向いていない／弱点／欠点は禁止）。
タイプに優劣なし。全員が主役。Revoは押しつけず“出口”として自然に。

## 使い始め方
1. `01-color-system.md` でアイコン・bio・カバーの色を確定
2. `card-templates.html` を Firefox で開き、表紙＋レボリスト＋よくある特性の3枚を書き出す
3. `02-posts.md` の「シリーズ予告」→「A-01 レボリスト」の順で投稿
4. 投稿後60分は返信に張り付く（初速オペ）
