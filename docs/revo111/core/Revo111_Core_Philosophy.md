# Revo111 Core Philosophy

## Revo111とは

Revo111は診断ではない。

人を固定的に分類するものでもない。

人が、

- 自分を知る
- 仲間を知る
- 環境を知る
- 活動を知る
- 成長を知る

ためのOSである。

## 基本思想

人には役割がある。

しかしその役割に優劣はない。

強い役割は、
今よく使っている力。

弱い役割は、
劣っている力ではない。

まだ使っていない力。

これから育つ可能性。

出会いによって開花する力。

## Revo111が目指すもの

多くの診断は、

「あなたは〇〇タイプです」

で終わる。

Revo111は違う。

目的は分類ではなく循環。

目的はラベルではなく成長。

目的は診断ではなく行動。

## 人は変化する

役割は固定ではない。

人は、

- 活動
- 仲間
- 環境
- 経験

によって変化する。

## 不足という考え方を採用しない

Revo111では、

足りない

欠けている

向いていない

相性が悪い

という表現を使わない。

代わりに、

- 眠っている力
- 育つ可能性
- 広げてくれる存在
- 開花させてくれる存在

という考え方を採用する。

## 仲間によって開花する

人は一人では完成しない。

違う役割の人と出会うことで、

得意が伸びる。

眠っていた力が育つ。

挑戦が続く。

未来が広がる。

## 第三者効果

一対一ではぶつかる関係もある。

しかし第三者が入ることで、

理解

翻訳

整理

循環

が生まれる。

## 与えると受け取る

応援を受け取る。

信頼を受け取る。

安心を受け取る。

受け取ったものが、

また誰かへ渡される。

Revo111は、
この循環を可視化する。

## DAOとの違い

DAOは自立分散型組織。

Revo111は循環型役割組織。

役割を見つける。

役割を育てる。

役割を組み合わせる。

役割を循環させる。

これによって、

人も

プロジェクトも

ブランドも

文化も

継続できる状態を目指す。

## Revo111のゴール

自分を知ることではない。

自分を活かすこと。

仲間を知ることではない。

仲間と未来を作ること。

診断結果を見ることではない。

行動すること。

そして、

応援が循環する文化を育てること。

それがRevo111である。
