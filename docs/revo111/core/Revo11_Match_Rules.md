# Revo11 Match Rules

## 基本思想

相性を判定するためのものではない。

誰と組むと、
どんな未来が生まれるかを示す。

Revo111では、

不足を埋める

ではなく、

可能性を広げる

という考え方を採用する。

# 共通ルール

最高の組み合わせとは、

似ている人ではない。

違う役割が出会い、

新しい未来が生まれる状態である。

Revo Matchとは、

相性診断ではなく、

未来創造診断である。
