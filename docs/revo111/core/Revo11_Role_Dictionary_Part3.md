# Revo11 共通思想

役割に優劣はない。

目立つ役割もあれば、

支える役割もある。

前に立つ人もいれば、

土台を作る人もいる。

重要なのは、

どの役割が優れているかではない。

どの役割を活かしているかである。

Revo111は、

人を分類するためではなく、

役割を活かすために存在する。
