# Revo11 Growth Routes

## 基本思想

役割は固定されない。

人は

・活動
・仲間
・環境
・経験

によって成長する。

Revo111では、

現在地を見るだけでなく、

次に育ちやすい役割

まで提案する。

# 共通ルール

低スコアの役割は弱点ではない。

次に育つ可能性である。

成長とは、

不足を埋めることではなく、

役割を広げることである。

Revo111は、

現在地ではなく、

未来地図を示すために存在する。
