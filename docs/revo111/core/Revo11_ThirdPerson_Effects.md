# Revo11 Third Person Effects

## 基本思想

相性だけでは未来は見えない。

第三者が入ることで、

理解

翻訳

整理

循環

が生まれる。

Revo111では、

二人の関係ではなく、

三人で生まれる未来を見る。

# 共通ルール

最高のチームとは

優秀な人を集めることではない。

違う役割が

適切な順番で

循環することである。

第三者効果とは

人を補うためではなく

未来を広げるために存在する。
