# Monitor B

## タイトル

Revo111 チーム循環モニター

---

## 目的

Revo111の診断結果を使い、

「誰と組むと未来が広がるか」

を検証する。

Monitor Bは、相性診断ではない。

チーム内で役割がどう循環するかを検証する。

---

# 基本思想

人は一人で完成しない。

しかしそれは、
不足しているという意味ではない。

違う役割の人と組むことで、

- 得意が伸びる
- 苦手だと思っていた力が育つ
- 活動が続く
- 想いが届く
- 未来が広がる

---
