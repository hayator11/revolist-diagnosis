# Monitor C

## タイトル

Revo111 活動適性モニター

---

## 目的

44問版の診断結果から、

「自分はどんな活動で力を発揮しやすいのか」

を提案できるか検証する。

Monitor Cは、Revo Funding / Revo Link / Revo Song への接続精度を見るための実験である。

---

## 仮説

人は「自分の役割」だけでは行動に移りにくい。

しかし、

- 向いている活動
- 合いそうなプロジェクト
- 必要な仲間
- 小さなクエスト

が見えると、次の行動を起こしやすくなる。

---

## 検証内容

### 1. 活動提案の納得感

診断結果で提案された活動がしっくりくるか。

---

### 2. Revo Funding接続

自分がプロジェクトを起案する側か、
応援する側か、
運営する側か、
広げる側かを検証する。

---

### 3. Revo Link接続

どんな人と出会うと活動しやすいかを検証する。

---

### 4. Revo Song接続

想いや物語を音楽・文章・発信に変える活動に関心があるかを検証する。

---
