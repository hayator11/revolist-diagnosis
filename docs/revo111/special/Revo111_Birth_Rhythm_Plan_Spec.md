# Revo111 生年月日リズムプラン 設計書

## 目的

「生年月日リズムプラン」は、生年月日を使用する独自のリサーチ要素と、Revo111の役割診断を組み合わせた番外編リサーチ版。

人の未来や性質を断定するものではなく、力が出やすい環境、流れ、タイミング、活動の方向性を見つけるための特別プランとして扱う。

特定の外部プログラムや既存サービスの公式版ではない。

## 検証したいこと

- Revo111役割ごとに、どの人生リズム表現が響くか
- ユーザーが知りたいのは、タイミング、環境、役割のどれか
- 生年月日入力に抵抗があるか
- 結果文が重くなりすぎず、行動につながるか
- コミュニティ参加導線として機能するか

---

## 生年月日の扱い

生年月日はセンシティブな情報として扱う。

最初のプロトタイプでは、入力は任意にする。

必ず以下を守る。

- 入力しなくても完了できる
- 使用目的を説明する
- 同意した人だけ入力する
- 外部には表示しない
- 人の未来や性質を断定しない
- 生まれた時間は必須にしない

---

## 入力パターン

### 生年月日なし

質問回答だけで結果を出す。

### 生年月日あり

同意したユーザーのみ、生年月日を入力する。

入力項目:

- 生年
- 生月
- 生日
- 生まれた時間がわかるか
- 生まれた時間
- 生まれた場所

## 5つの検証軸

| 表示名 | 意味 |
|---|---|
| 伸びる力 | 成長・挑戦・始まり |
| 伝える力 | 表現・熱量・広がり |
| 支える力 | 安心・育成・居場所 |
| 整える力 | 判断・構造・美意識 |
| 深める力 | 知恵・洞察・準備 |

## 質問項目

### 伸びる力

```text
1. 新しい環境に入ると、自分の可能性が広がる感覚がある
2. 小さくてもいいので、前に進む実感があると元気が出る
3. 誰かの成長を見ると、自分も動きたくなる
4. 今の自分には、次の挑戦で育つ可能性があると感じる
```

### 伝える力

```text
5. 想いや体験を言葉や表現にすると、周囲に熱が広がる
6. 人前で話す、発信する、見せることで力が出ることがある
7. 場の空気が明るくなる瞬間に喜びを感じる
8. 誰かの心に火が灯るような関わり方をしたい
```

### 支える力

```text
9. 誰かが安心できる場をつくることに価値を感じる
10. すぐに結果が出なくても、じっくり育てることができる
11. 人の話を受け止めたり、居場所を整えたりすることが多い
12. 自分の存在が、誰かの土台になるならうれしい
```

### 整える力

```text
13. ものごとの本質や優先順位を見極めたい
14. 整った形、美しい流れ、無駄のない仕組みに惹かれる
15. 境界線やルールがあると、安心して力を使える
16. 大切なものを選び取ることで、未来が澄んでいく感覚がある
```

### 深める力

```text
17. 一人で考える時間が、自分の力を回復させてくれる
18. 表に出る前に、情報や感覚を深く蓄えることが多い
19. 人の言葉の奥にある気持ちや流れを感じ取ることがある
20. すぐに動くより、流れを読んでから動く方が自然に進める
```
