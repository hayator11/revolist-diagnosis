# Revo111 価値の流れプラン 設計書

## 目的

「価値の流れプラン」は、Revo111の役割診断に、価値の生み出し方・広げ方・育て方・仕組み化の要素を組み合わせた番外編リサーチ版。

仕事、副業、活動、コミュニティ参加の中で、ユーザーがどのように価値を生み出しやすいかを可視化する。

特定の外部プログラムや既存サービスの公式版ではない。

## 検証したいこと

- どのRevo111役割が、企画・人・タイミング・仕組みのどこに反応しやすいか
- 仕事や副業への関心につながる表現は何か
- コミュニティ参加につながる言葉は何か
- どの結果パターンが感想入力につながりやすいか
- どの活動提案が行動につながりやすいか

## Revo111役割の入力方法

### 既に結果がある場合

質問:

```text
あなたのRevo111診断結果がわかる場合は選んでください
```

選ぶ内容:

- メイン役割
- サブ役割
- 補助役割

### 結果がわからない場合

簡易の役割スナップショット質問を使う。

---

## 4つの検証軸

| 表示名 | 意味 |
|---|---|
| 始まりをつくる力 | 未来を描き、企画やアイデアを生む |
| 人と広げる力 | 人と熱量をつなぎ、活動を広げる |
| 流れを育てる力 | 場の流れを読み、無理なく育てる |
| 仕組みにする力 | 仕組みを整え、続く形にする |

## 質問項目

### 始まりをつくる力

```text
1. 新しい企画やアイデアを考える時間があると元気が出る
2. まだ形になっていない可能性を見つけるのが好き
3. 誰もやっていない切り口を考えると動きたくなる
4. 未来のイメージを話して、人を前向きにしたい
```

### 人と広げる力

```text
5. 人と話すことで、自分の考えが広がっていく
6. 誰かの魅力や可能性を見つけるのが好き
7. 人を紹介したり、場をつないだりすることに喜びを感じる
8. 一人で進めるより、誰かと熱量を共有すると動きやすい
```

### 流れを育てる力

```text
9. 今は動く時か、待つ時かを感覚的に見ている
10. 周囲の状態を見ながら、無理なく進めるのが得意
11. 現場の空気や人の気持ちを感じ取って動くことが多い
12. 長く続く関係や活動を、少しずつ育てたい
```

### 仕組みにする力

```text
13. 情報や手順を整理すると安心して動ける
14. 続けられる仕組みやルールを作るのが好き
15. 数字、記録、データから改善点を見つけるのが楽しい
16. 一度作った流れを、より使いやすく整えたくなる
```


## Revo111との重ね方

基本:

```text
価値の流れタイプ × Revo111メイン役割
```

例:

```text
レボリスト × 未来を描き、始まりをつくる人

コミュニケーター × 人と熱量をつなぎ、広げる人

アレンジャー × 仕組みを整え、積み上げる人
流れを整え、続けられる形にする人
```
