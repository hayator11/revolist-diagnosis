# Revo111 マスター目次

## Revo111の目的

Revo111は、性格診断ではない。

人を固定するためのものではなく、以下を見つけるための成長OSである。

- 今の役割
- 成長ルート
- 一緒に動きやすい仲間
- 未来を広げる可能性
- プロジェクトやコミュニティでの関わり方

## 最終目的

Revo111は、人を分類して終わるためのものではない。

目的は、診断ではなく行動である。

目的は、役割を固定することではなく、育てることである。

目的は、ひとりで抱える挑戦を減らし、役割が循環する文化をつくることである。
