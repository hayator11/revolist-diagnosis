# Icebreak 33 外部検証案内文

## 目的

Icebreak 33 / レボリスト診断を外部テスターに試してもらい、結果画面の納得感・わかりやすさ・シェアしたくなるか・オフ会や会話に使えそうかを確認する。

この検証では、診断結果の正解・不正解を判定しない。結果を見た人が「自分にあるかも」と思えるか、違和感があるならどこか、会話のきっかけとして使えそうかを見る。

本名や個人情報は不要。`centeredResultSummary` やSupabaseの内部情報は回答者には見せない。

## 外部テスター向け案内文

### 基本文

こんにちは。

いま、Icebreak 33 という短い診断の検証をしています。

33問に答えると、今の回答から見える「人との関わり方」や「場で出やすい役割」が表示されます。

所要時間は3〜5分くらいです。

これは性格を決めつけるものではなく、結果画面の言葉がしっくりくるか、わかりやすいか、会話のきっかけに使えそうかを確認するためのテストです。

本名や個人情報は不要です。

結果を見たあと、検証フォームで「しっくりきた部分」「違和感があった部分」を教えてもらえると助かります。

しっくりこない感想も大歓迎です。むしろ改善のヒントになります。

## テスターに確認してほしいポイント

結果を見ながら、以下を気軽に見てもらう。

- 結果の最初のカードがわかりやすいか
- 「あ、自分にあるかも」と思える要素があるか
- 結果が長すぎないか
- 役割名がこじつけっぽく見えないか
- 結果を誰かに見せたくなるか
- 自己紹介や会話のきっかけに使えそうか
- オフ会で人とつながるきっかけになりそうか
- 違和感がある場合、どの言葉・どの表示に違和感があるか

## テスト手順

1. 診断URLを開く
2. 33問に回答する
3. 結果を見る
4. 結果URLまたは診断IDを控える
5. 検証フォームに回答する

検証フォームでは、結果のしっくり度や、違和感のあった部分を聞く。

診断結果のスクリーンショット共有は任意。個人情報が入らない範囲でお願いする。

## 検証フォーム案内文

このフォームは、Icebreak 33 の診断結果をよりよくするための検証アンケートです。

あなた個人を評価するものではありません。

本名や個人情報の入力は不要です。

診断結果を見て、しっくりきた部分や違和感のあった部分を教えてください。

「ここは違う気がする」「この言葉はわかりにくい」も、とても大事な感想です。

所要時間は3〜5分ほどです。

- 役割ごとに違和感が偏っていないか
