# レボリスト11 化学反応ユニット v0

## 目的

11の役割を単体で説明するのではなく、組み合わせた時に何が生まれるかで見せる。

名称は後から添える。まずは「どんな働きか」「組むと何が起きるか」を伝える。

## 中核ユニット

### ぶっ飛んだ発想を、実行され、理解される形にする

| 働き | 名称 | 役割 |
|---|---|---|
| 常識の外から、社会にあったら面白い可能性を出す人 | クレイジスト | 誰も思いつかない角度から、実際に始めてしまう |
| 新しいことに挑戦し、前に進める人 | レボリスト | 実行力で火をつける |
| わかりやすく言語化し、理解される形にまとめる人 | ロジカルマイスター | 発想と実行を、伝わる構造にする |

この3人が組むと、発想がただの思いつきで終わらず、実行され、理解され、広がり始める。

```text
常識の外の発想
  + 実行する力
  + わかりやすい構造
= 社会に伝わる新しい挑戦
```

## 図での見せ方

円環ではなく、化学反応ユニットとして見せる。

- 役割単体ではなく、3人の組み合わせを1つの反応として見せる
- 中央に「生まれるもの」を置く
- 各役割は説明を先に、名称を後に置く
- 目的別に表示するユニットを変える

目的別:

| 目的 | 優先して見せるユニット |
|---|---|
| オフ会 | 安心して話し、一歩を踏み出す場 |
| ワークショップ | 情報を集め、流れを整え、仕組みにする |
| 合コン | 安心、会話、発見される関係 |
| プロジェクト | ぶっ飛んだ発想を、実行され、理解される形にする |
| クリエイティブ | 世界観を、人に届く価値へ磨く |
