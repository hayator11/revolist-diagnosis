# レボリスト診断 マッチング・化学反応モデル v0

## 目的

診断結果を「あなたは何タイプです」で終わらせず、誰と組むと動きやすいか、どんな場で化学反応が起きやすいか、どの組み合わせをイベント・ワークショップ・合コン・プロジェクトに活かせるかまで扱う。

このモデルは、特定の既存診断をコピーするものではない。Person-Environment Fit、Complementary Fit、チーム構成研究、心理的安全性、Belbin Team Roles、RIASEC、Big Five/HEXACO などを参考に、レボリスト診断用に再構成する。

## 参考にする研究・モデル

| 領域 | 参考にする考え方 | レボリスト診断への反映 |
|---|---|---|
| Person-Environment Fit | 人と環境の適合。似ている適合と補完する適合がある | 同質性だけでなく、足りない力を補う関係を見る |
| Complementary Fit | 相手が持っていないものを補う関係 | 「必要なタイプがいる感じ」を設計する |
| Psychological Safety | 安心して発言・挑戦できる場がチーム学習に影響する | マッチングには安心軸を必ず入れる |
| Team Composition | 能力・性格・役割の組み合わせが成果に影響する | 席順やチーム編成で多様性と役割の被りを調整する |
| Belbin Team Roles | チーム内役割として人を見る | 固定人格ではなく、場で出る役割として扱う |
| RIASEC | 1タイプ断定ではなく上位コードで見る | 上位2〜3特性で相性を見る |
| Big Five / HEXACO | 安定した測定軸と短縮版の作り方 | 質問削減・妥当性検証の参考にする |

## 現状での最大値

現時点で目指す最大値は、以下の4層判定。

### 1. 個人特性

多軸スコアから、その人が自然に出しやすい力を見る。

- はじめる
- 描く
- つなぐ
- 整える
- 支える
- 不確実性耐性
- 心理的安全性
- 実行初速
- 継続/保守
- 非同調性
- 表現衝動
- 証拠探索
- 調整力
- 公開/発信耐性

### 2. 補完関係

自分に少ない軸を相手が持っているかを見る。

例:

- はじめる人 + 整える人
- 描く人 + 磨く人
- つなぐ人 + 安心を育てる人
- 非同調の人 + 仕組みにする人

### 3. 化学反応

単なる相性ではなく、組んだ時に何が起きるかを見る。

| 組み合わせ | 起きやすい反応 |
|---|---|
| レボリスト × ロジカルマイスター | 未来が設計図になる |
| レボリスト × アレンジャー | 挑戦が続く流れになる |
| クレイジスト × マックスデザイナー | 違和感が企画になる |
| イメージマイスター × プルミエルクラフター | 世界観が信頼される品質になる |
| コミュニケーター × ソウルオーナー | 会話が居場所になる |
| ムーブメンター × レボリスト | 熱量が行動へ広がる |
| インフォレイダー × ロジカルマイスター | 情報が判断基準になる |

### 4. 目的別マッチング

目的によって「良い組み合わせ」は変わる。

| 目的 | 重視する組み合わせ |
|---|---|
| オフ会 | 会話が生まれる、安心して話せる、違う力が近い |
| ワークショップ | 発想、整理、発表、実行がそろう |
| 合コン | 距離感、安心感、会話の広がり、自然な自己開示 |
| プロジェクト | 旗振り、設計、運営、品質、応援がそろう |
| コミュニティ | つなぐ、支える、整える、続ける力がそろう |

## 引き出され方の設計

相性は「似ている」「補っている」だけでは足りない。

実際の場では、相手によって自分の出方が変わる。

例:

- 普段は人前で話さない人が、聞くのが上手い人の前では自然に話し始める
- 自分では当たり前だと思っていたことを、別の人が「それはすごいアイデア」と見つけてくれる
- 感覚で話す人の発想を、理論的な人が構造化して形にする
- 感情で動く人の熱量を、現実的な人が実行手順へ変える
- 慎重な人が、安心して小さく試せる場を作ってもらうことで動き出す

このため、診断では本人の特性だけでなく「誰の前でその力が出るか」を見る必要がある。

### 引き出し軸

| 軸 | 見ること |
|---|---|
| 聞き手によって話せる | 安心して聞いてくれる相手がいると自己開示しやすい |
| 発見されると動く | 自分の当たり前を価値として見つけてもらうと力が出る |
| 感覚を言語化してもらう | 直感やイメージを言葉・構造にしてもらうと進みやすい |
| 理論をあたためてもらう | 論理や仕組みに、人の温度を足してもらうと伝わりやすい |
| 感情を現実に落とす | 熱量を段取りや小さな行動に変えてもらうと続きやすい |
| 現実を広げてもらう | 実務や現実感に、可能性や遊びを足してもらうと広がる |
| 慎重さを安全な実験にする | 不安を否定せず、試せる範囲に区切ってもらうと動ける |

## 視座・認知スタイル・表現スタイル

マッチングには、役割だけでなく「どこを見ているか」「何を材料に動くか」「どう表現するか」が必要。

### 視座

| 視座 | 見ること | マッチング上の意味 |
|---|---|---|
| 自分視点 | 自分の感覚、納得、やりたいことを重視する | 自己理解・創作・挑戦の火種になりやすい |
| 対人視点 | 相手の気持ち、関係性、場の空気を重視する | 会話、安心、紹介、橋渡しに強い |
| チーム視点 | 役割、段取り、全体の流れを重視する | ワークショップ、席順、運営設計に強い |
| 社会視点 | 社会課題、未来、仕組み、文化を重視する | プロジェクト化、活動化、理念化に強い |

### 認知スタイル

| スタイル | 見ること | 補完しやすい相手 |
|---|---|---|
| 感覚型 | 直感、雰囲気、違和感、イメージで捉える | 言語化・構造化が得意な人 |
| 言語化型 | 感覚や思考を言葉にできる | 感覚や経験を多く持つ人 |
| 発想型 | 選択肢や可能性を広げる | まとめる人、実行する人 |
| 構造化型 | 散らばった情報を整理する | 発想する人、感情で動く人 |
| 感情駆動型 | 共感、熱量、好き嫌いから動く | 現実化・段取りが得意な人 |
| 現実駆動型 | 実現性、手順、生活実感から動く | 可能性を広げる人 |

### 表現スタイル

| スタイル | 見ること |
|---|---|
| 話すことで見つかる | 会話しながら考えが出る |
| 聞かれることで出る | 良い聞き手がいると深く話せる |
| 書くことで整う | 文章やメモで考えが形になる |
| 見せることで伝わる | 図、写真、デザイン、雰囲気で伝わる |
| 動くことでわかる | 試しながら理解する |

### Wealth Dynamics から学ぶ観点

公開情報で確認できる範囲では、Wealth Dynamics は Roger J. Hamilton によるプロファイリングシステムで、Jung の心理類型や I Ching などに関連づけられ、8つの成功パスを扱うモデルとされている。

一般に知られる枠組みでは、Dynamo / Blaze / Tempo / Steel のようなエネルギーの違いと、Creator / Star / Supporter / Deal Maker / Trader / Accumulator / Lord / Mechanic のようなプロファイルを扱う。

レボリスト診断で学ぶべきなのは、特定の名称や型をコピーすることではなく、単に職業タイプを当てるよりも、エネルギーの出方や役割の補完を重視している点である。

レボリスト診断では、その考え方を以下のように取り込む。

- 発想する人、広げる人、整える人、守る人を分けて見る
- 1人で完結するのではなく、組み合わせで価値が生まれると考える
- 自分が自然に出せる力と、相手に引き出される力を分けて見る
- 「自分にないもの」だけでなく「自分の力を出してくれる相手」を見る
- 感覚・言語化・発想・構造化・感情・現実化の違いを、マッチングの材料にする

ただし、既存モデルをそのまま写すのではなく、日本人向けの回答傾向とレボリスト11役割に合わせて再設計する。

## マッチングスコア案

総合マッチングは1つの点数にしない。理由が見えるように複数スコアで出す。

```text
matchingScore =
  0.30 * complementaryFit
  + 0.20 * sharedPurposeFit
  + 0.20 * psychologicalSafetyFit
  + 0.15 * chemistryPotential
  + 0.15 * roleBalance
```

### complementaryFit

相手が自分に少ない軸を持っているか。

### sharedPurposeFit

活動目的が近いか。オフ会、合コン、プロジェクトでは重みを変える。

### psychologicalSafetyFit

安心して話せる関係が作れそうか。

### chemistryPotential

組み合わせたときに新しい動きが生まれそうか。

### roleBalance

役割が被りすぎず、必要な役割がそろうか。

## 2人・3人・5人の設計

### 2人

最初は会話が動く補完関係を優先。

### 3人

2人で足りない力を3人目で補う。ここが最重要。

例:

- レボリスト + ロジカルマイスター + アレンジャー
- クレイジスト + マックスデザイナー + ロジカルマイスター
- コミュニケーター + ソウルオーナー + ムーブメンター

### 5人

5つの力がなるべく揃うようにする。

オフ会の席順では、5人卓なら5つの力の分散を優先する。

## データで育てる方法

最初から正解扱いしない。以下をイベントごとに集める。

### 参加前

- 診断回答
- 目的
- 話したいテーマ
- 参加時の不安/期待

### イベント中

- 席順
- 同卓メンバーの力
- 会話が始まったか

### イベント後

- 話しやすかった人
- また話したい人
- 何が生まれたか
- オープンチャットに参加したか
- 次のイベントに参加したいか

## 質問を短くするための方針

最初は質問数を増やしてよい。

その代わり、データが溜まったら以下で削る。

- 判定に効いていない質問
- 他の質問と相関が高すぎる質問
- 回答が中央に寄りすぎる質問
- 日本人が理想回答で選びやすい質問
- タイプ間の差を作れていない質問

## 合格条件

- レボリスト/クレイジストが中庸回答で多数派にならない
- 「似ている相性」と「補う相性」を分けて出せる
- 2人の相性だけでなく、3人目候補を出せる
- 目的別にマッチングの重みを変えられる
- イベント後アンケートで、実際に話しやすかった組み合わせを検証できる
- データが集まるほど質問を減らせる

## 実装順

1. 多軸質問バンクを作る
2. 33問オフ会版を作る
3. マッチングスコアを内部計算だけで出す
4. 結果画面には「話してみたい人」「3人目候補」「同卓理由」を出す
5. イベント後アンケートで実感値を集める
6. 実感値をもとに重みを調整する
