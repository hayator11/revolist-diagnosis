# レボリスト11 五角形ベースの化学反応モデル v0

## 目的

固定の組み合わせではなく、5つの力の形から多様な組み合わせが生まれることを見せる。

レボリスト診断の核は、11役割を固定ペアで並べることではない。

まず5つの力の五角形があり、その人の形、相手の形、チームの形が重なることで、相性や化学反応が見えてくる。

## 5つの力

| 力 | 意味 | 関連しやすい役割 |
|---|---|---|
| はじめる力 | まだないものに一歩を置く | レボリスト / クレイジスト |
| 描く力 | 可能性や世界観を形にする | マックスデザイナー / イメージマイスター |
| つなぐ力 | 人・想い・場の間に流れを作る | コミュニケーター / アレンジャー |
| 整える力 | 情報や役割を整理し土台を作る | インフォレイダー / ロジカルマイスター / アレンジャー |
| 支える力 | 安心感や完成度を守り育てる | ムーブメンター / プルミエルクラフター / ソウルオーナー |

## 固定組み合わせにしない

三組の化学反応例は、あくまで代表例。

実際には、以下で組み合わせが変わる。

- 本人の強い力
- 本人の空きスロット
- 相手の強い力
- 目的
- 場の人数
- その場で必要な会話/実行/安心/構造

## 五角形で見る3つの層

### 1. 5つの力: 何を渡しているか

5つの力は、その人が場に自然に渡している価値を見るための層。

これは「役割名」より前に見せる。

```text
この人は、場に何を持ち込むのか
この人の近くにいると、何が動きやすくなるのか
```

### 2. 4つの動き方: どう力を出すか

ウェルスダイナミクスの4周波数から得たヒントは、そのまま名前を使うのではなく、レボリスト11では以下の「動き方」として扱う。

| レボリスト11での表現 | 参考にした周波数 | 見ているもの |
|---|---|---|
| 創発型 | ダイナモ的 | 未来・可能性・新しい始まりから動く |
| 共鳴型 | ブレイズ的 | 人・熱量・会話の広がりから動く |
| 現場型 | テンポ的 | 状況・タイミング・安心感から動く |
| 構造型 | スチール的 | 情報・仕組み・再現性から動く |

同じ「はじめる力」が高い人でも、創発型ならアイデアから始まり、共鳴型なら人を巻き込む形で始まり、構造型なら仕組みを作る形で始まる。

### 3. 11役割: 周囲からどう見えやすいか

11役割は、5つの力と4つの動き方が組み合わさった結果として見える役割。

そのため、質問は「レボリストですか？」を直接聞くだけではなく、複数の軸から判断する。

```text
5つの力 = 何を渡すか
4つの動き方 = どう動くか
11役割 = その組み合わせが役割としてどう現れるか
```

## 五角形で見る3つの状態

### 1. 自分の形

いま強く使っている力と、まだ借りると動きやすい力を見る。

```text
強い力 = 自然に渡せるもの
空きスロット = 近くにいると動きやすい人
```

### 2. 相手との重なり

相手の五角形と重ねて見る。

- 同じ力が高い: わかり合いやすい
- 違う力が高い: 補完が起きやすい
- 自分の空きが相手の強み: 会話や行動が動きやすい
- 両方の空きが同じ: 3人目が必要

### 3. チームの形

3人・5人で五角形を重ねる。

- 3人: 足りない力を1つ補うと動きやすい
- 5人: 5つの力が分散すると場が回りやすい

## 組み合わせの見せ方

結果画面では、固定の「この3人」とは出さない。

代わりに以下を出す。

```text
あなたが自然に渡せる力
近くにいると動きやすい力
今の場に足すとよい力
```

例:

```text
あなたは「はじめる力」が強めです。
近くに「整える力」の人がいると、挑戦が理解される形になります。
さらに「つなぐ力」が入ると、人へ広がり始めます。
```

この時に、役割名は後から添える。

```text
整える力の人:
複雑なことを仕組みにする人 / ロジカルマイスター

つなぐ力の人:
人と人の間に会話を生む人 / コミュニケーター
```

## 目的別の重み

| 目的 | 優先する力 |
|---|---|
| オフ会 | つなぐ力 / 支える力 / 補完する力 |
| ワークショップ | 描く力 / 整える力 / つなぐ力 |
| 合コン | 支える力 / つなぐ力 / 描く力 |
| プロジェクト | はじめる力 / 整える力 / つなぐ力 |
| クリエイティブ | 描く力 / 支える力 / つなぐ力 |

## 実装メモ

共通ロジックは、診断ごとにバラバラに作らず、以下の順で使う。

1. 質問回答から15個の詳細軸を出す
2. 詳細軸から5つの力と4つの動き方を出す
3. 5つの力と4つの動き方から11役割の候補を出す
4. マッチングでは、役割名だけではなく「5つの力の補完」「4つの動き方の噛み合い」「目的別の重み」を使う

## 図の方針

- 中央に5つの力の五角形を置く
- 11役割は五角形の周囲に配置する
- 固定ペアではなく、線を「可変ルート」として見せる
- 自分の形、相手の形、チームの形が重なる余地を残す
- 代表的な反応は「例」として小さく表示する
