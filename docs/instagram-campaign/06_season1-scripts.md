# 06｜シーズン1 制作台本（11タイプ紹介カルーセル）

`03_content-playbook.md` のテンプレ①を、全11タイプ分に流し込んだ制作用の台本。
スライド本文は `src/data/revotypes.ts` を一次ソースにしている。
**この台本＋ `slide-generator.html`（同フォルダ）で、実際のスライド画像を書き出せる。**

各タイプ 9スライド構成（1080×1350 / 4:5）：
```
1 フック（あるある）        6 こう動くと力が出る（行動指針）
2 共感「わかる…」           7 相性：ベストパートナー
3 タイプ発表（名前+コピー）  8 今いる環境で試す
4 強み（4つ）               9 チートシート要約 ＋ CTA
5 自然に渡しているもの
```

---

## 制作の進め方
1. `slide-generator.html` をブラウザで開く
2. タイプを選ぶ → 9枚のスライドが表示される
3. 各スライドをスクショ or 印刷→PDF/PNGで書き出し（1080×1350で設計済み）
4. Instagramに9枚のカルーセルとして投稿、下のキャプションを貼る
5. 投稿したら `content-log.csv` に記録し、`backlog.md` の該当タイプにチェック

---

## 投稿順（おすすめ）
反応の取りやすい"はじめる力"系から始め、5つの力をバランスよく回す。

1. レボリスト → 2. コミュニケーター → 3. ロジカルマイスター → 4. イメージマイスター →
5. ムーブメンター → 6. アレンジャー → 7. マックスデザイナー → 8. インフォレイダー →
9. ソウルオーナー → 10. プルミエルクラフター → 11. クレイジスト

---

## キャプション（各タイプ共通フォーマット）

```
{フックのあるある1行}
…そんなあなたは【{タイプ名}】かもしれません。

{catchcopy}

このタイプは、{gives[0]}を自然に周りへ渡しています。
組むと動きやすいのは【{bestPair}】タイプ。

👉 あなたは何タイプ？ プロフィールのリンクから無料診断（約1分）
📌 保存して自分の"取扱説明書"に／当てはまった人はコメントで教えてください

#レボリスト診断 #性格診断 #自己分析 #強み診断 #チームづくり
```

> リールにする場合：スライド3→1→4→7の順で速いテンポにし、冒頭3秒に「{あるある}」を出す。

## 各タイプの中身（生成元データ）

`slide-generator.html` はこの表と同じ値を使って自動でスライドを組む。手作業で作る場合の早見表。

| タイプ | フック（1枚目） | ベストパートナー | 今いる環境で（8枚目） |
|--------|----------------|----------------|---------------------|
| レボリスト | 「まだ誰もやってないから面白い」とつい言ってしまう | アレンジャー | 職場や学校で「やってみよう」と最初に声を上げる |
| コミュニケーター | 無意識に「みんな楽しめてるかな?」を気にする | ソウルオーナー | 「全員の意見を優しくまとめる役」を楽しむ |
| ロジカルマイスター | 勢いより「どうすれば動くか」を構造で考える | レボリスト | 会議の議論を、その場で構造化して見せる |
| イメージマイスター | 「なんかいい」「なんか違う」を誰より鋭く感じる | ソウルオーナー | 資料や発表に、視覚的な美しさを加える |
| ムーブメンター | ためらう人がいると、つい背中を押したくなる | レボリスト | ためらっている人に、一番熱い言葉をかける |
| アレンジャー | あなたが段取りを引くと全員が驚くほど動ける | レボリスト | 役割分担を最初に美しく整理する係を担う |
| マックスデザイナー | 「もっと面白くできるはず」が常に頭にある | ロジカルマイスター | 会議で「もっと面白くするなら?」と問いかける |
| インフォレイダー | 気づけば誰よりその分野に詳しくなっている | レボリスト | 判断に必要なデータを先回りして集める |
| ソウルオーナー | 誰かの心の機微に、真っ先に気づいてしまう | コミュニケーター | 話しづらそうな人に、誰より早く声をかける |
| プルミエルクラフター | 「もう少し良くできる」で最後まで仕上げ続ける | レボリスト | 成果物の最終品質チェックの砦を担当する |
| クレイジスト | 「なぜみんなそのやり方で納得できるの?」と思う | ロジカルマイスター | 「本当にそう?」と固定観念に痛快に問いかける |

> 強み・渡しているもの・行動指針の全文は `revotypes.ts` を参照（ネガティブ表現に言い換えないよう注意）。
