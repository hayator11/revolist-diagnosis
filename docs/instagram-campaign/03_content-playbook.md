## C. 投稿台本テンプレ①：11タイプ紹介カルーセル（8〜10枚）

各タイプ共通の骨格。`{ }` を差し替えるだけ。

```
[1] フック：{キーカラー背景}「{あるある1行}」＋ 小さく「あなたかも?」
[2] 共感：{openingText 冒頭1文（"わかる…"）}
[3] タイプ発表：{日本語名} ／ {catchcopy} ／ {キーカラーのドット}
[4] 強み：{strengths 4つをアイコン付きで}
[5] 自然に渡しているもの：{gives 3つ}
[6] こう動くと力が出る：{actionPrinciples から1〜2つ}
[7] 相性：ベストパートナーは【{bestPair}】＋ ひとこと理由
[8] 今いる環境で：{currentEnvTips から1つ}
[9] チートシート：このタイプを1枚に要約（保存版）
[10] CTA：保存＆シェア／「あなたは何タイプ? プロフのリンクから無料診断」／次タイプ予告
```

キャプション例：
```
{あるある1行}…そんなあなたは【{名前}】タイプかも。
{catchcopy}
👉 あなたは何タイプ？ プロフィールのリンクから無料診断（1分）
保存して自分の"取扱説明書"に📌
—
#レボリスト診断 #性格診断 #自己分析 #強み診断 #{テーマ}
```

## D. 投稿台本テンプレ②：あるある集カルーセル（保存主力）

```
[1] フック：「こういう人、あなたの周りにいませんか？」
[2〜7] あるある列挙：1枚1あるある（表情/職場シーンのイラスト＋短文）
[8] 種明かし：「実はこれ全部、【{タイプ名}】の特徴です」
[9] 活かし方：この人が輝く環境／組むといい相手
[10] CTA：「当てはまった人はコメントで🙋／診断で確かめる」
```
※「職場あるある」「学校あるある」「LINEの返信あるある」など切り口を変えて量産可。
※種明かしを最後に置くと**完読率**が上がる（引っぱる構造）。

## E. 投稿台本テンプレ③：組み合わせで能力アップ（相性・チーム）

```
[1] フック：「この2タイプが組むと、能力が跳ね上がる」
[2] 2タイプ提示：{A}×{B}（両方のキーカラーで割った背景）
[3] Aが渡すもの / Bが渡すもの（お互いの空きスロットを埋める）
[4] だから何が起きる：{goodWithDetail / teamNote の要点}
[5] 3人目を足すと：{thirdPerson} でさらに安定
[6] 人数別の考え方：2人=強いが詰まりやすい / 3人=まとまる / 4人=3+1 / 5人=分散して動く
[7] CTA：「あなたと相方のタイプは？ 診断してタグ付けしてシェア」
```

## G. リール ネタ帳（新規リーチ用）

1. **色でわかる11タイプ**：11色が順に切り替わり「あなたはどの色?」で締め
2. **タイプあるある早回し**：1タイプ2秒、テンポよく11連発
3. **"この動きをする人、実は…"**：職場のワンシーン→タイプ名を種明かし
4. **最強チームの作り方**：2人→3人→5人へ、色ブロックが組み上がる
5. **診断やってみた（結果リアクション）**：結果画面を見せて「当たってる…」
6. **奇数チームがまとまる理由**：3人・5人が動きやすい話（診断の設計思想）

各リール共通：冒頭3秒で結論／字幕必須／カバーはブランドカラー準拠。

## H. ストーリーズ ネタ帳（自己診断ファネル）

- 投票：「会議、あなたはどっち? ①最初に動く（レボリスト系）②全体を整える（アレンジャー系）」
- クイズ：「この特徴、何タイプ? 『もう少し良くできる』が口ぐせ」→ 答え：プルミエルクラフター
- 質問箱：「あなたのチームに"足りない力"は?」
- リンク誘導：新カルーセルの告知＋「診断はこちら」リンクスタンプ
- ハイライト常設：`11タイプ` / `あなたは何タイプ?` / `相性` / `Revoって?`

## I. Revoへの導線（出口として自然に）

診断で「自分の力を活かしたい」と思った人にだけ、そっと選択肢を出す。押しつけない。
- タイプ紹介の最後や相性投稿で、たまに「この力が活きる場所の一例」としてRevo活動に触れる程度
- 各タイプの `activities`（例：レボアート/レボリンク/レボソング/レボファンディング）を"活かせる場"の例として自然に添える
- 基本はあくまで「まず今いる環境（職場・学校・家族）で試そう」を主役にする

## J. 制作チェックリスト（投稿前に確認）

- [ ] 1枚目フックは小さいプレビューでも読めるか（極太・高コントラスト）
- [ ] 1スライド15〜20語以内か
- [ ] キーカラー/文字色の可読性ルール（暗背景=白／明背景=濃紺）を守れているか
- [ ] 右下にブランド署名 `レボリスト診断` があるか
- [ ] 最終スライドにCTA（保存/シェア/診断リンク/次予告）があるか
- [ ] キャプション1行目が第2のフックになっているか＋問いかけがあるか
- [ ] ハッシュタグ3〜5個、タイプ名・悩みワードを本文に入れたか
- [ ] **ネガティブ表現ゼロ**（相性が悪い/向いていない/弱点/欠点/失敗を使っていない）
- [ ] タイプに優劣をつけていないか
