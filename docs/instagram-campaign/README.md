## この設計書について

「11タイプの紹介」「よくある特性（あるある）」「組み合わせによる能力アップ」を、
**2026年最新のInstagramアルゴリズムに最適化した"型"** で発信し続けるための土台です。

## 継続運用ループ（このOSの心臓）

```
  ✏️ 制作 ──▶ 📅 予約 ──▶ 🚀 投稿 ──▶ 📊 計測 ──▶ 🔍 週次レビュー ──▶ 🔄 更新
     ▲                                                                    │
     └────────────────── 学びが次の制作を決める（毎週1周）──────────────────┘
```

**受け渡しの型（あなた ⇄ AIカンパニー）**
1. あなたが投稿し、数字（インサイト）を持ってくる
2. AI部長＋分析担当が `05_feedback-loop.md` の意思決定マトリクスで「来週の3決定」を返す
3. 制作担当が次の投稿を作り、つばさくんが `backlog.md` と予約枠を更新
4. → 1週間後、また1へ（止めないことが全て）

## 30秒サマリー（AI部長への引き継ぎ用）

**イメージカラー**
- ブランド基調：**Revo Ink `#0E1330`**（濃紺）を背景に、全タイプ色を最も鮮やかに見せる
- ブランド主役色：**Revo Indigo `#4F46E5`**（"組み合わせを設計するOS" の知性）
- 行動喚起色：**Revo Coral `#FF4D6D`**（"診断する" ボタン・着火の赤）
- 11タイプは「5つの力」でカラーファミリー化（着火＝赤／描く＝紫桃／つなぐ＝シアン／整える＝青緑／支える＝琥珀紫）

**発信の仕組み（2026アルゴリズムの結論）**
- 主戦場は**カルーセル**（全形式で最高エンゲージ率）。1枚目フック＋最後にチートシート要約
- 指標は「いいね」より**保存(Save)・送信(DM Send)**。DM送信1回 ≒ いいね約15回の価値
- 頻度より**1本の質**。フィード週3〜5・リール週2〜4・ストーリーズほぼ毎日
- ハッシュタグは3〜5個。それより**キャプション内のキーワード（診断名・タイプ名）**で検索に乗せる
- リールで「発見」、カルーセルで「深い理解と保存」、ストーリーズで「自己診断へ誘導」

**投稿ロードマップ**
1. シーズン0：世界観ティーザー（イメージカラー発表 / "あなたは何タイプ?"）
2. シーズン1：11タイプ紹介（1タイプ1カルーセル ×11）
3. シーズン2：よくある特性＝あるある（保存誘発の主力）
4. シーズン3：組み合わせで能力アップ（相性・チーム設計）
→ 以降ループ。詳細は `03_content-playbook.md`。

## 運用の合言葉（レボリスト診断の大原則を厳守）

- ネガティブ表現は絶対に使わない（❌相性が悪い/向いていない/弱点 → ✅違う強み/伸びしろ/眠っている力/力を引き出す存在）
- タイプに優劣はない。それぞれ独自の力を持つ
- Revoは押しつけない。診断で自分を知った人が"自然に辿り着く出口"として紹介する
