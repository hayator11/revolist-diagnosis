# 01｜レボリスト診断 ブランドカラーシステム

Instagram発信の視覚的な一貫性を担保するためのカラー定義。
**アプリ（`src/data/revotypes.ts`）で既に使われているタイプ色を「正」として踏襲**し、
Instagram上で見栄えするようにサブカラー・グラデ・背景ルールを追加している。

---

## 1. マスターブランドカラー

レボリスト診断は「**11の力を束ねるOS（プリズム）**」。
だからブランド単色は主張しすぎず、11タイプの色を一番きれいに見せる"器"として設計する。

| 役割 | 名前 | HEX | 使いどころ |
|------|------|-----|-----------|
| ベース（背景） | **Revo Ink** | `#0E1330` | 全スライドの基本背景。濃紺が11タイプ色を最も鮮やかに見せる |
| カード/第2背景 | Revo Ink 2 | `#171C3D` | カード・帯・引用ボックス |
| ブランド主役 | **Revo Indigo** | `#4F46E5` | ロゴ、見出しアクセント、"設計・OS"の知性を象徴 |
| 行動喚起（CTA） | **Revo Coral** | `#FF4D6D` | 「診断する」ボタン、最終スライドの矢印、リンク誘導 |
| ペーパー（明面） | Revo Paper | `#F6F4FF` | 明るいトーンで見せたい回の背景 |
| 本文（暗背景上） | Ink Text | `#F5F5FA` | Revo Ink上の本文 |
| 本文（明背景上） | Paper Text | `#1A1A2E` | Revo Paper上の本文 |
| 補助グレー | Muted | `#8A90B8` | キャプション補足・注釈 |

### ブランド・スペクトラム（表紙／ロゴロックアップ用グラデ）
11タイプの色を虹状に並べた帯。アカウントの世界観カット、ハイライトカバー、
「11タイプ全員集合」投稿の背景に使う。

```
#DC2626 → #FF6B3D → #D97706 → #059669 → #0891B2 → #1D4ED8 → #4F46E5 → #7C3AED → #6D5BD0 → #DB2777 → #BE185D
（赤 → 橙 → 琥珀 → 緑 → シアン → 青 → 藍 → 紫 → 菫 → 桃 → マゼンタ）
```

## 2. 「5つの力」＝カラーファミリー

11タイプは診断上「5つの力」に属する。色もこの5系統でまとめると、
フィードのサムネイル一覧が"意味を持った虹"に見え、統一感と多様性を両立できる。

| 力 | 系統色 | 属するタイプ | 感情キーワード |
|----|--------|------------|--------------|
| 🔥 はじめる力 | 温色（赤〜マゼンタ） | レボリスト / クレイジスト | 着火・突破・革命 |
| 🎨 描く力 | 紫〜桃 | マックスデザイナー / イメージマイスター | 拡張・感性・世界観 |
| 🤝 つなぐ力 | シアン | コミュニケーター | 架け橋・安心・調和 |
| 🧭 整える力 | 緑〜青〜藍 | インフォレイダー / ロジカルマイスター / アレンジャー | 洞察・設計・循環 |
| 🌱 支える力 | 琥珀〜ブロンズ〜菫 | ムーブメンター / プルミエルクラフター / ソウルオーナー | 応援・職人・癒し |

> ⚠️ **ソウルオーナーだけ要調整メモ**
> アプリ上はソウルオーナーの `color` が `#7C3AED`（マックスデザイナーと同じ値）になっている。
> Instagramで並べると2タイプが同色で見分けられないため、
> **ソウルオーナーは癒し系の菫 `#6D5BD0` に寄せる** ことを推奨（マックスデザイナーは彩度の高い紫のまま残す）。
> 将来的に `revotypes.ts` の `soulowner.color` を更新しても良い。

## 4. 文字・可読性ルール（アルゴリズムに効く）

2026年のフィードは**小さなプレビューでフックが読めるか**が勝負。以下を厳守。

- **1スライド15〜20語まで**（マイクロラーニング）。詰め込まない
- 見出しは極太（900ウェイト）＋高コントラスト。キーカラー背景には白 or Revo Ink
- タイプ名は必ず「日本語名＋キーカラーのドット」で表示（一覧性）
- テキストは**セーフゾーン（中央80%）**に。UIやプロフィール見切れを回避
- ブランド署名は右下に小さく `レボリスト診断` ＋ Revo Coralのドット（毎回同じ位置＝ブランド記憶）

### アクセシビリティ
- ブロンズ `#92400E` / インディゴ系など暗い色の上は**必ず白文字**
- 琥珀 `#D97706` / シアン `#0891B2` の上は Revo Ink `#0E1330` の濃い文字が読みやすい
- 迷ったら「背景が暗い→白文字 / 背景が明るい→濃紺文字」

## 5. スライド寸法・書き出し

| 用途 | 比率 | ピクセル |
|------|------|---------|
| カルーセル（フィード主力） | 4:5 | **1080 × 1350** |
| リールカバー / 縦動画 | 9:16 | 1080 × 1920 |
| ストーリーズ | 9:16 | 1080 × 1920 |
| 正方形（一覧見栄え重視の回） | 1:1 | 1080 × 1080 |

カラー値はすべて [`colors.json`](./colors.json) にも格納。テンプレ自動生成やOG画像生成に流用可。
