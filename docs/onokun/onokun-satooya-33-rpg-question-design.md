# おのくん里親さん 33問RPG型診断 設問設計

最終更新: 2026年6月30日

## 目的

この文書は、「おのくん里親さん 11ご縁タイプ診断」を33問のRPG型診断として育てるための設問設計メモです。

診断の目的は、里親さんを分類・評価することではありません。おのくんとのご縁の育て方を楽しく見える化し、里親さん同士の会話や、東松島・防災・ものづくり・コミュニティへの自然な接続を生むことです。

中心に置く考え方:

```txt
みんな違ってみんないい。
あなたとおのくんのご縁も、きっと世界にひとつ。
```

## 1. 33問にする理由

33問は、11タイプそれぞれに3問ずつ置ける設計です。

11タイプを1問ずつで判定すると、その日の気分や設問の好みに左右されやすくなります。3問ずつにすることで、タイプの雰囲気を少し立体的に見られます。

33問にする理由:

- 11タイプそれぞれに同じ重みを持たせられる。
- 1タイプ3問にすることで、単発の回答ぶれをやわらげられる。
- 「おのくんを知る」「里親として動く」「ご縁が広がる」のように章立てできる。
- 所要時間を長くしすぎず、でも物語として楽しめる長さにできる。
- 結果ページで「あなたの旅の傾向」として見せやすい。

設問数の印象:

- 11問: 気軽だが、結果が浅くなりやすい。
- 22問: 初期公開には扱いやすいが、RPG感は少し弱い。
- 33問: 体験として残りやすく、11タイプの検証にも向く。

## 2. RPG型診断にする理由

この診断は、性格診断というより「うちの子とのご縁を育てる小さな旅」として見せます。

RPG型にする理由:

- 診断を「採点」ではなく「旅」にできる。
- 里親さんが主人公になりやすい。
- おのくんを案内役として自然に登場させられる。
- 東松島、里帰り、防災、ものづくり、つながりを章ごとに扱いやすい。
- 結果を「称号」「クエスト」「相棒」として楽しく見せられる。

RPGの見立て:

- 主人公: 里親さん
- 相棒: うちの子のおのくん
- 旅の舞台: 日常、東松島、里帰り、集まり
- クエスト: 今日できる小さなおの活
- 仲間: 相棒里親さん、LINEオープンチャット、希望者向け協力の場、イベント参加者
- たどり着く先: 楽しいご縁が、防災や地域とのつながりにもなる状態

## 3. プロローグ質問の扱い

プロローグ質問は、スコア判定に入れる質問ではなく、診断の世界観に入ってもらうための導入として扱います。

ただし、回答はすべて選択式にします。自由入力は入れません。

理由:

- 入力式にすると、診断の心理的ハードルが上がる。
- 何を書けばよいか迷う時間が増える。
- 震災や個人的な体験に触れる可能性があり、扱いが重くなる。
- 結果生成が複雑になり、初期公開では診断精度の検証がしづらくなる。
- スマホでの回答体験が止まりやすくなる。

目的:

- 里親さんの気持ちをあたためる。
- 「正解を当てる診断」ではないことを伝える。
- おのくんとの出会いや、うちの子への気持ちを思い出してもらう。
- 結果ページの言葉に少し反映できる余白をつくる。

プロローグ質問の例:

- うちの子と出会ったときに近かった気持ちは？
  - うれしい
  - ほっとした
  - ちょっと不思議
  - 誰かに見せたくなった
  - じわじわ好きになった
- おのくんを迎えてから、増えた気がする時間は？
  - 写真を撮る時間
  - 眺める時間
  - 誰かに話す時間
  - おでかけを考える時間
  - ものを大切にする時間
- うちの子を誰かに紹介するとしたら、最初に話したいことは？
  - 見た目や表情
  - 出会ったきっかけ
  - 飾っている場所
  - 一緒に行きたい場所
  - なんだか家族みたいなところ

扱い方:

- 判定スコアには入れない。
- 回答は選択式にする。
- 文章入力欄は置かない。
- 結果に「あなたの旅のはじまり」として、選択した気持ちを短く表示する余地を残す。
- 個人情報や深い体験を答えさせない。

## 4. 3章構成

33問は、11問ずつの3章構成にします。

### 第1章: おのくんを知る

テーマ:

おのくんの背景、手づくり感、里親文化、東松島とのつながりに触れる章。

役割:

- おのくんをすでに知っている人には、あたたかく思い出してもらう。
- はじめて知る人には、押しつけずに世界観へ入ってもらう。
- 震災や防災を直接クイズ化せず、背景への敬意を持つ。

### 第2章: うちの子との楽しみ方を見つける

テーマ:

写真、飾り方、里帰り、会話、ものづくり、情報収集など、里親さんそれぞれの楽しみ方を見る章。

役割:

- 11タイプの個性を自然に測る。
- 「どれが上か」ではなく「どんな楽しみ方が近いか」を見る。
- 結果ページのタイプ名とつながる体験にする。

### 第3章: ご縁を広げるクエスト

テーマ:

誰かに話す、集まりに参加する、里帰りを考える、防災につながる場に触れるなど、ご縁が外へ広がる章。

役割:

- 結果後の行動につなげる。
- LINEオープンチャットで交流し、希望者を防災×帽祭、レボリストLab、協力の場へ自然につなげる。
- 防災を「怖いから備える」ではなく、「楽しいから集まる、集まるからつながる、つながるから備えになる」として表現する。

## 5.1. 1問1タイプ加点にしない理由

おのくん里親さん診断は、これまでの端的な自己評価型診断よりも、回答の意味を深く扱います。

単純な設計:

```txt
Q. 写真を撮るのが好きですか？
YES = うちの子世界観里親に加点
NO = 加点なし
```

この形だけだと、回答者の自然なご縁の育て方を十分に見られません。たとえば「写真を撮るのが好きではない」と答えた人は、魅力を見せる力がないのではなく、言葉で伝える人かもしれないし、場を整える人かもしれないし、家族のように見守る人かもしれません。

そのため、1つの設問は「あるタイプである証拠」だけでなく、「他のタイプらしさが見える証拠」にもなるように設計します。

基本方針:

- 1つの設問を、1つのタイプだけの質問にしない。
- 5段階回答のすべてに意味を持たせる。
- 高い回答は表側のタイプの証拠として扱う。
- 低い回答は別タイプの入口が見える証拠として扱う。
- 中間回答は、場面依存・相棒タイプ・サブタイプの手がかりとして扱う。
- 「違う」は不足ではなく、別のご縁の育て方として読む。

## 5.2. 回答値ごとの証拠設計

各設問は、回答値ごとに複数タイプへの意味を持たせます。

```txt
5 = 表のご縁タイプが強く出ている
4 = 表のご縁タイプが自然に出やすい
3 = 場面によって変わる / サブタイプや相棒タイプの手がかり
2 = 別の入口を優先しやすい
1 = 反対側・補完側のご縁タイプが見えやすい
```

例:

```txt
Q. うちの子の写真を撮るとき、背景や置き方まで考えたくなる。
```

この設問の表側は「うちの子世界観里親」です。ただし、回答値ごとの意味は次のように分けます。

| 回答 | 読み取り | 証拠になりやすいタイプ |
| --- | --- | --- |
| 5 | 見せ方・世界観づくりに自然に目が向く | うちの子世界観里親 |
| 4 | 写真や飾り方で魅力を伝えやすい | うちの子世界観里親 / わくわく未来図里親 |
| 3 | 場面によって、見せ方より会話や記録を優先する | ご縁おしゃべり里親 / まちの発見里親 |
| 2 | 見せ方より、行き先・段取り・手ざわりを大切にしやすい | おでかけ段取り里親 / ちくちく愛情里親 |
| 1 | 写真で見せるより、そばにいる安心や言葉での紹介を大切にしやすい | ぬくもり見守り里親 / ことば整え里親 |

このように、低い回答も「世界観がない」ではなく、別の育て方が見える回答として扱います。

## 5.4. 診断結果で出すべきもの

結果は「一番点が高いタイプ」だけで終わらせません。

表示したい判定:

- メインご縁タイプ
- サブご縁タイプ
- 補助ご縁タイプ
- ご縁クラスター
- 回答から見えた証拠
- 相棒里親さん
- 今日の里親ミッション
- 話しかけるきっかけ

結果ページの考察文では、次のように説明します。

```txt
あなたは「うちの子世界観里親」の傾向が強く出ています。
写真や飾り方で魅力を見せる回答が多く、
一方で、会話や情報を通じてご縁を広げる回答も見えました。

つまり、うちの子の世界観を見せながら、
そこから誰かとの会話や発見につなげる里親さんです。
```

この形にすると、結果が単なるラベルではなく「なぜそう見えたか」を含む里親カードになります。

## 5.5. タイプを見分けるための対比設計

似ているタイプ同士は、設問で丁寧に見分けます。

### めんどくしぇ突破里親 / わくわく未来図里親

- めんどくしぇ突破里親: 変わったことを思いつき、まず試したくなる。
- わくわく未来図里親: 楽しみ方の可能性や未来図を広げたくなる。

見分ける設問軸:

- すぐ試すか。
- 未来の構想を描くか。
- 周りが笑う意外性に惹かれるか。
- これからの広がりに惹かれるか。

### うちの子世界観里親 / ことば整え里親

- うちの子世界観里親: 写真、飾り方、雰囲気で魅力を見せる。
- ことば整え里親: 想い、背景、魅力を伝わる言葉にする。

見分ける設問軸:

- 先に見せ方が浮かぶか。
- 先に説明文や紹介文が浮かぶか。
- 感覚で伝えたいか。
- 言葉で整理して届けたいか。

### ご縁おしゃべり里親 / ぬくもり見守り里親

- ご縁おしゃべり里親: 会話の入口をつくる。
- ぬくもり見守り里親: 安心できる空気を育てる。

見分ける設問軸:

- 自分から話題をひらくか。
- 話せる空気をそっと待つか。
- 人と人をつなぎたいか。
- 帰ってこられる場をあたためたいか。

### 背中ぽんぽん里親 / おでかけ段取り里親

- 背中ぽんぽん里親: 誰かの一歩をやさしく後押しする。
- おでかけ段取り里親: 動きやすい流れや準備を整える。

見分ける設問軸:

- 気持ちを後押しするか。
- 具体的な段取りを組むか。
- 不安をやわらげるか。
- 参加の流れを見える化するか。

### ちくちく愛情里親 / まちの発見里親

- ちくちく愛情里親: ものと想いを丁寧に育てる。
- まちの発見里親: 場所や情報を見つけ、誰かに届ける。

見分ける設問軸:

- 手元のものに愛情を注ぐか。
- 外の情報や場所に目が向くか。
- 手ざわりを大切にするか。
- 発見を共有したくなるか。

## 5.6. 多様な診断方式の採用

先行診断の設計を参考に、おのくん版では複数の聞き方を混ぜます。

使う設問形式:

- 5段階同意
- 場面選択式
- どちらに近いかを選ぶ二択
- 優先順位を選ぶ設問
- プロローグの選択式導入質問

役割:

- 5段階同意: 安定したスコアを取る。
- 場面選択式: 診断意図を見せず、自然な目線を見る。
- 二択: 似ているタイプ同士を見分ける。
- 優先順位: サブタイプや補助タイプを見る。
- プロローグ選択式: 結果の余白や言葉の温度を、負担なくつくる。

注意:

- 難しい心理テストに見せない。
- 設問ごとに回答負荷を上げすぎない。
- 里親さんが「うちの子との旅を選んでいる」感覚を保つ。
- 防災や震災に関わる設問では、知識テストや恐怖訴求にしない。

## 6. おのくんを知る設問方針

「おのくんを知る」設問は、知識テストにしません。

避けること:

- 震災のつらさをクイズ化する。
- 被災体験の詳細を答えさせる。
- 正解・不正解でおのくん理解を測る。
- 知らない人を置いていく。

大切にすること:

- おのくんが生まれた背景を、敬意を持って扱う。
- 手づくりのぬくもりを伝える。
- 東松島とのつながりをやさしく紹介する。
- 知っている人も、はじめての人も参加しやすくする。

設問の方向性:

- 「知っているか」ではなく「どう感じるか」を聞く。
- 「正しい説明を選ぶ」ではなく「どの関わり方が近いか」を聞く。
- 背景説明は設問前後の短いコラムとして添える。
- 深い話題は、診断内で掘り下げすぎず、公式情報や活動紹介へつなげる。

## 7. 里親さんクエスト設問方針

里親さんクエストは、結果後に実際の小さな行動へつながる設問です。

設問で見たいこと:

- 写真を撮る。
- 飾る。
- 誰かに話す。
- 里帰りを考える。
- 情報を見つける。
- 集まりを整える。
- ものを大切にする。
- 言葉にする。
- そっと見守る。

表現方針:

- 「やらなければ」ではなく「ちょっとやってみたくなる」。
- 大きな行動より、今日できる小さな一歩にする。
- 里親さんそれぞれの生活ペースを尊重する。
- 参加できない人にも、家でできるおの活を用意する。

結果へのつなげ方:

- 「今日の里親ミッション」として表示する。
- 「話しかけるきっかけ」として会話文に変換する。
- LINEオープンチャットで話しやすく、希望者が次の協力へ進みやすいお題にする。

## 8. 防災×帽祭・レボリストLabへの自然な接続

防災×帽祭やレボリストLabは、診断の入口ではなく、結果後の自然な選択肢として扱います。

接続の考え方:

```txt
楽しいから集まる。
集まるからつながる。
つながるから備えになる。
```

防災への接続は、恐怖や不安を強めるためではなく、日常のつながりが結果的に備えになることを伝えるために行います。

見せ方:

- 「このタイプにおすすめのクエスト」として紹介する。
- 防災×帽祭は、楽しく集まりながら備えを考える場として紹介する。
- レボリストLabは、企画・実験・言葉づくり・場づくりに関わりたい人の次の場所として紹介する。
- 「参加必須」ではなく「気になる人はこちら」とする。

タイプ別接続例:

- めんどくしぇ突破里親: 楽しい防災アイデアを考える。

## 11. 震災や防災を扱うときの注意

震災や防災を扱うときは、診断の楽しさよりも、背景への敬意を優先します。

必ず守ること:

- 震災のつらさをクイズ化しない。
- 怖がらせて防災へ誘導しない。
- おのくんが生まれた背景を、敬意を持って扱う。
- 防災は「楽しいから集まる、集まるからつながる、つながるから備えになる」という形で表現する。
- 被災経験の有無や内容を入力させない。
- 悲しみや不安を煽るビジュアルにしない。
- 「知らないこと」を責めない。
- 防災を義務や正しさとして押しつけない。

使ってよい表現の方向:

- あたたかいつながり
- 日常の中の備え
- 楽しい場が、いざというときの支えになる
- 誰かと顔が見える関係
- 里帰りや集まりから生まれる安心

避ける表現の方向:

- 恐怖訴求
- ショック表現
- 正解を当てるクイズ
- 知識の上下をつける言い方
- 防災意識の低さを責める言い方
- 被災体験の消費に見える演出
