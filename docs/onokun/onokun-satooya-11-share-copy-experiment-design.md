# おのくん里親さん 11問診断 SNSシェア文言 実験設計

## 目的

11問診断の結果シェア文言を固定せず、複数パターンで出し分ける。
どの文言がシェアされやすいかを管理画面で追跡し、反応が弱い文言を更新していく。

狙いは、単なるSNS拡散ではなく、以下を起こすこと。

- 結果を見た本人が「ちょっと言いたい」と思う。
- 見た人が「自分もやってみたい」と思う。
- 親バカサロンで「私はこれだった」と会話が生まれる。
- 反応が良い言葉を見つけ、診断全体のコピー改善に使う。

## 出し分け比率

基本比率:

- 通常コピー: 約90%
- 当たりコピー: 約5%
- おもしろコピー: 約5%

この比率は固定ではなく、管理画面で将来的に変更できる前提にする。
初期は安全に通常コピーを中心にし、当たり・おもしろは小さく試す。

## コピー構造

シェア文言は以下の部品で構成する。

1. 冒頭コピー
2. 診断タイプ名
3. タイプ別ひとこと
4. 呼びかけ
5. URL

例:

```text
うちの子とのご縁、ちょっと見えました。
私は「ただいま火つけ里親」でした。
里帰り欲に火がつくタイプらしいです。

あなたはどんなご縁を育てる里親さん？
https://...
```

## コピー種別

### 通常コピー

一番多く出す標準コピー。
安心して誰でもシェアしやすい文言にする。

必要数:

- 冒頭コピー: 11種類
- 呼びかけ: 11種類

タイプごとに固定でもよいが、将来的には同じタイプ内でも複数パターンを持てるようにする。

### 当たりコピー

約5%で表示する、少し特別感のあるコピー。
「当たり」と言っても、優劣を感じさせない。
小さなラッキー感、限定感、見つけた感を出す。

初期は1種類。

例:

```text
ちょっとレアなご縁カードが出ました。
```

### おもしろコピー

約5%で表示する、思わず誰かに見せたくなるコピー。
ふざけすぎず、おのくんらしいゆるさに留める。

初期は1種類。

例:

```text
うちの子、診断中にちょっとドヤ顔してました。
```

## 初期コピー案

### 冒頭コピー 11種類

1. うちの子とのご縁、ちょっと見えました。
2. おのくんとの楽しみ方、名前がつきました。
3. 私の親バカ、どうやらこのタイプらしいです。
4. うちの子が連れてくるご縁を診断しました。
5. 里親さんとしてのクセ、出ました。
6. おの活の方向性、ちょっとバレました。
7. うちの子との関わり方に、タイプがありました。
8. 親バカサロンで名乗りたくなる結果が出ました。
9. おのくんとのご縁、世界にひとつでした。
10. うちの子目線だと、私はこう見えるらしいです。
11. みんな違ってみんないい、私のご縁タイプはこれでした。

### 呼びかけ 11種類

1. あなたはどんなご縁を育てる里親さん？
2. うちの子タイプ、見てみませんか？
3. あなたのおの活にも名前をつけてみませんか？
4. 親バカ仲間のタイプも気になります。
5. 結果を持って、親バカサロンで話したいです。
6. 同じタイプの里親さん、いるかな？
7. 相棒タイプの里親さんにも会ってみたいです。
8. うちの子自慢のきっかけにどうぞ。
9. おのくんとのご縁、ちょっと見える化してみませんか？
10. あなたのうちの子は、どんなご縁を連れてきますか？
11. 親バカ診断、思ったより当たるかもしれません。

### 当たりコピー 1種類

```text
ちょっとレアなご縁カードが出ました。
```

### おもしろコピー 1種類

```text
うちの子、診断中にちょっとドヤ顔してました。
```

## 出し分け仕様

結果ページ表示時に、シェアコピーのバリアントを1つ決める。

保存する値:

- `share_variant_id`
- `share_variant_kind`: `normal` / `lucky` / `funny`
- `opening_copy_id`
- `call_to_action_copy_id`
- `main_type_key`
- `main_revo_type_key`
- `result_id` または `diagnosis_id`

比率:

- `normal`: 0.90
- `lucky`: 0.05
- `funny`: 0.05

重要:

- 同じ結果URLを開き直したときにコピーが毎回変わると検証しづらい。
- `diagnosis_id` と `session_id` をもとに、同じユーザーには同じバリアントを出す。
- シェアボタンごとに表示文言は同じにする。

## 計測イベント

最低限、以下を記録する。

### share_copy_assigned

結果ページで、どのシェア文言が割り当てられたか。

記録項目:

- `event_name`: `share_copy_assigned`
- `diagnosis_id`
- `main_type_key`
- `share_variant_id`
- `share_variant_kind`
- `opening_copy_id`
- `call_to_action_copy_id`
- `device`
- `created_at`

### share_button_clicked

ユーザーがシェアボタンを押したか。

記録項目:

- `event_name`: `share_button_clicked`
- `diagnosis_id`
- `main_type_key`
- `share_variant_id`
- `share_variant_kind`
- `share_channel`: `x` / `line` / `native` / `copy`
- `device`
- `created_at`

### open_chat_clicked

シェア文言と親バカサロン誘導の関係を見るために記録する。

記録項目:

- `event_name`: `open_chat_clicked`
- `diagnosis_id`
- `main_type_key`
- `share_variant_id`
- `share_variant_kind`
- `device`
- `created_at`

### タイプ別

- 11タイプごとの診断回数

## 改善ルール

最初は最低でも100表示以上を目安に見る。
表示数が少ない段階では、文言の優劣を決めつけない。

改善対象:

- 表示数が十分あるのにシェア率が低いコピー
- 親バカサロン遷移率が低い呼びかけ
- 特定タイプだけ極端に反応が弱いコピー

更新方針:

- 通常コピーは大きく変えすぎず、少しずつ差し替える。
- 当たりコピーとおもしろコピーは、反応が良ければ2種類目、3種類目を追加する。
- おもしろコピーが強すぎて診断の温かさを壊す場合は弱める。
- 当たりコピーが優劣に見える場合は、レア感ではなく「今日のご縁感」に寄せる。

## 注意点

- タイプに優劣があるように見せない。
- 「当たり」を出しても、他の人が外れに見えないようにする。
- 震災や防災をネタ化しない。
- 怖がらせてシェアや参加を促さない。
- 個人情報を保存しない。
- SNSで実際に投稿完了したかまでは取得できないため、まずはシェアボタン押下を指標にする。

## 将来拡張

- 管理画面からコピーを有効/無効にする。
- コピーごとの比率を管理画面から変更する。
- タイプごとに強いコピーを自動で優先する。
- 親バカサロン内で反応がよかった言葉をコピー候補に追加する。
- 18問相棒診断への流入元として、どのシェア文言が効いたかを見る。
